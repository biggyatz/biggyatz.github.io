# blog.biggyatkumarpandey.com.np: project hub

**Live:** <https://blog.biggyatkumarpandey.com.np/>

A single link-in-bio page with every live project by Biggyat Kumar Pandey: TaskNTrade, the AI demos and the web apps, each with a screenshot and links to try it and read the code. Static HTML, no build step, free on GitHub Pages. Experience, case studies and teaching live on the [portfolio](https://biggyatkumarpandey.com.np/).

| File | What it is |
| --- | --- |
| `index.html` | The hub page (light/dark, mobile-first) |
| `img/` | Profile photo and project screenshots |
| `farmkart/` | Static live version of Farmkart, a VIT team e-commerce project (original PHP/MySQL code: [adwyaitpawar/Farmkart](https://github.com/adwyaitpawar/Farmkart)) |

To add a project, copy one `<article class="card">` block in `index.html`, add a 720×456 screenshot to `img/`, and push to `main`. GitHub Pages republishes automatically.
